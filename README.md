# پروژه تولید QR Code

## معرفی

این پروژه یک ابزار ساده و کاربردی برای تولید QR Code با استفاده از PHP است. کاربر می‌تواند متن یا لینک مورد نظر خود را وارد کرده و QR Code متناظر با آن را در اندازه‌های مختلف دریافت نماید.

## پیش‌نیازها

- PHP نسخه 7.0 یا بالاتر
- دسترسی به اینترنت برای استفاده از API تولید QR Code
- ترمینال یا محیط اجرای PHP (مانند Termux)

## نصب و راه‌اندازی [Termux]

### گام اول: نصب PHP

در محیط Termux:

```

pkg update
pkg install php

```

### گام دوم: اجرای سرور

در پوشه پروژه دستور زیر را اجرا کنید:

```

php -S localhost:8081

```

### گام سوم: دسترسی به برنامه

مرورگر خود را باز کرده و به آدرس زیر مراجعه کنید:

```

http://localhost:8081

```

## ساختار پروژه

```

qr-code/
├── index.php    # فرم ورود اطلاعات و انتخاب اندازه
└── qr.php       # تولید و نمایش QR Code

```

## نحوه استفاده

1. متن یا لینک مورد نظر را در کادر مربوطه وارد کنید.
2. اندازه QR Code را از میان گزینه‌های موجود انتخاب نمایید.
3. بر روی دکمه "تولید QR Code" کلیک کنید.
4. در صفحه جدید می‌توانید QR Code تولید شده را مشاهده و دانلود کنید.

## امکانات

- تولید QR Code از متن یا لینک
- انتخاب اندازه‌های مختلف (کوچک، متوسط، بزرگ، خیلی بزرگ)
- قابلیت دانلود QR Code تولید شده
- رابط کاربری واکنش‌گرا و سازگار با موبایل
- پشتیبانی از زبان فارسی

## نکات فنی

- این پروژه از سرویس رایگان qrserver.com برای تولید QR Code استفاده می‌کند.
- برای استفاده آفلاین می‌توان از کتابخانه‌های محلی PHP مانند phpqrcode استفاده نمود.
- رنگ‌بندی و استایل صفحات از طریق فایل‌های CSS داخلی قابل تنظیم است.
